# Sessions always restart at Research Stage 1; upgrades persist

A returning player keeps Power, Beam, discoveries, and best stats, but every Session still starts Stage 1 / Research 0 / Suspicion 0. Persistence is a head-start on the build, not a skip of the core loop. Overflow Research does not spill into the next stage; Stage 5 filling wins immediately with no fifth Breakthrough. There is no session timer; Suspicion is the only fail pressure.
